# Snore Battle｜打呼卡牌對戰

Pygame 同機雙人回合制卡牌遊戲的基礎可玩版本。規則依 `遊戲規格.md`，測試卡牌與平衡值可修改。

## 開始遊戲

直接雙擊 `啟動遊戲.cmd`。本專題已內附 `runtime/python.exe`（Windows x64 Python 3.12.10）與 `.vendor` 的 Pygame，啟動時不再依賴系統 Python 或 Codex 更新路徑。移動或複製專題時請保留 runtime、.vendor、data、assets 與 snorebattle 等資料夾。

其他電腦建議安裝 Python 3.12 或更新版本，於專題資料夾終端機執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

`.vendor` 是本機 Windows／Python 3.12 的依賴，不應帶到不同 Python 版本使用；移至其他環境時以該環境重裝，或移開 `.vendor` 再使用虛擬環境。

## 玩法與操作

- 開始遊戲 → 調整初始數值、每種牌的張數 → 開始對局。
- 開局自動落點並進入行動。出牌、換牌或略過後自動換人落點，鏡頭平滑移動後即可繼續行動。
- 打呼者在高度達到正負閾值時，可得固定分或額外抽一張，也可略過。
- 打巴掌者在正高度可打巴掌。得分暫為 `int(高度 / 巴掌分母 + 得分加成)`，需平衡測試。
- 巴掌清除效果、雙方道具，跳過出牌，直接交給打呼者下一次落點；目前橫軸持續。
- 選手牌後出 1 張並補滿上限，或棄 1 抽 1，也可略過；滑鼠滾輪或左右箭頭捲動手牌。
- 道具出牌後裝備，下一個自己的回合起使用。每回合最多一次，可以和角色行動任意排序。只有空欄能裝備。
- 上方落點固定於波形區內部寬度的 1/2；過去保留，未來可見範圍受預覽設定控制。
- 不遮手牌，換人後顯示接手玩家的手牌。尚未實作連線；連線是後續必做項目。
- `F3` 開關紀錄視窗；`Esc` 返回主選單。回到選單後新開對局會建立新遊戲，尚未提供中途存讀檔／恢復按鈕。

## 檔案位置

| 位置 | 用途 |
|---|---|
| `data/config.json` | 預設測試數值 |
| `data/cards.json` | 卡牌資料、組成與效果參數 |
| `snorebattle/core.py` | 狀態、操作命令、回合規則 |
| `snorebattle/effects.py` | 波形處理器、特殊道具能力註冊 |
| `snorebattle/wave.py` | 波形計算及歷史版本 |
| `snorebattle/achievements.py` | 成就進度追蹤 |
| `snorebattle/app.py` | Pygame 畫面與操作 |
| `snorebattle/assets.py` | 字型、圖片、音效及音樂入口 |
| `saves/settings.json` | 遊戲內儲存的設定，會覆蓋 data 預設值 |
| `saves/achievements.json` | 本機共用的成就解鎖紀錄 |
| `saves/logs/*.jsonl` | 每局獨立事件紀錄，含 seed、初始牌組、命令與結算事件 |

若修改 `data` 後沒看到數值改變，先檢查 `saves/settings.json` 的已儲存設定。

## 新增卡牌／道具

複製 `data/cards.json` 中一筆資料，給不同 `id`，修改 `copies` 與 `effects` 即可組合既有效果。不需要在回合流程判斷卡名。

波形處理器在 `effects.py` 用 `@wave_handler('新種類')` 註冊。全新道具在 `TOOL_HANDLERS` 註冊函數，再於卡牌的 `tool` 指定種類及參數。新狀態／即時效果則需補上規則核心的領域處理，不能僅填未註冊名稱。

持續效果依加入順序處理。波形變更約 1 個橫軸時間單位漸入，暫時效果到期前約 1 單位漸出；巴掌重置也平滑過渡。舊版本保留歷史，永久效果也能被巴掌清除。`data/config.json` 的 `wave_fade` 可調整此長度。

## 本版測試決策（可再調整）

- 振幅／閾值 50、週期 12、間隔 1.5、總長 45、預覽 3；打呼得 10 分，巴掌高度除以 5 取整數。
- 恰好等於終點可完成該回合，只有超過才結算。縮短終點至目前位置之前時，該牌結算後立即結束。
- 時間增減牌作為持續效果保存；巴掌清除後回到原終點，但目前 x 不歸零。巴掌不能倒轉已完成的抽牌、分數與歷史。
- 角色行動每回合最多一次；使用道具不重新給予角色行動。主動棄道具不算使用次數。
- 抱枕只改目前縱軸落點，朝 0 移動且不穿越 0，不修改函數與過去曲線。
- 波形加成從出牌位置之後漸入，期間採 `[開始, 結束)` 並於到期前漸出；原落點保持不變。sin 加成從效果起點計算相位。
- 基礎振幅／週期牌依當前基礎分量計算改動差值，再加入當前運算結果；先前的放大不會回頭套在後來的新改動上。後加入的放大則作用於整體。
- 「關燈」先只遮波形區；「重整」先定義為對手全手牌進棄牌區，再抽回同張數，可能抽回同牌。
- 棄掉的牌及所有離場道具都進共用棄牌區；若抽牌與棄牌區皆空，就不補牌。
- 成就為測試範例：同一玩家連續三次出同種牌（棄牌／略過中斷）、正負兩側得分、三次巴掌、完成對局。進度本局計算，解鎖跨局共用保存。

## 驗證

```powershell
python -m unittest discover -s tests -v
python main.py --smoke 5 --battle --screenshot preview.png
```

核心測試不依賴 Pygame。連線擴充時，權威端接收 `Command(player, action, card_uid, expected_revision)`，執行同一套規則；`Game.view(player)` 是玩家資料投影起點。網路傳輸、登入、大廳、斷線重連及完整序列化快照尚未實作。

鏡頭平移預設 650 毫秒，為真實動畫時間；波形漸入／漸出是橫軸時間，兩者互相獨立。

選牌預覽：任何階段點擊波形牌，上方保留青色原波形，增加紫色虛線預覽；再點同張可取消。預覽包含 FIFO、漸入漸出且不真正出牌。
