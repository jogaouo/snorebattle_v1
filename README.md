# Snore Battle｜打呼卡牌對戰

Pygame 回合制卡牌遊戲，正式入口提供單人PvE，同機雙人與測試工具保留於開發者快捷鍵。規則依 `遊戲規格.md`，測試卡牌與平衡值可修改。

## 開始遊戲

Windows 64 位元：從 GitHub 下載 ZIP 後，先完整解壓縮，再雙擊 `啟動遊戲.cmd`。不需另裝 Python、Pygame，也不需連網。

- 專案內附 `runtime/python.exe`（Windows x64 Python 3.12.10）。
- 首次啟動會檢查 Pygame，若尚未安裝，從 `dependencies/pygame-ce-2.5.6-windows-py312.zip` 驗證並解壓到 `.vendor`，接著啟動遊戲。
- 後續啟動直接使用本機已準備好的 Pygame，不會每次重裝。
- 下載／複製專案時，保留 `bootstrap.py`、`dependencies`、`runtime`、`data`、`assets` 與 `snorebattle`。請勿直接在 ZIP 內點啟動檔。
- `.vendor` 是自動產生的資料夾，不需要提交 Git；`dependencies` 中的離線包需要提交並推送到 GitHub。
- 若出錯，啟動視窗會保留訊息。離線包遺失或損毀時，重新下載完整專案。

若要使用自己安裝的 Python 開發，可自行建立環境（以下以 Python 3.12 為例）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

內附環境與離線包限 Windows 64 位元／Python 3.12；其他平台請使用自己的 Python 環境，依 `requirements.txt` 安裝依賴。

啟動時為一般可拖曳、可縮放視窗，依桌面大小自動縮小，最多使用約90%的桌面寬高，避免小螢幕或顯示縮放造成標題列超出畫面。內部畫布仍為1280×840，畫面與滑鼠座標會等比例轉換；可拖曳視窗邊緣自行調整大小。

## 玩法與操作

- 主選單「單人模式」→選角色→中等難度對戰。玩家當打呼者時對上固定 `loose_1`；當打巴掌者時對上固定 `tight_0`。直接使用目前設定與牌堆，不需要同層的 snorebot。選角色後直接開局，不會自動跳教學；新手教學由主選單獨立進入。
- 正式PvE只為玩家自己的操作計算個人成就；完成一場對局可解鎖完成成就。電腦手牌不公開，波型預覽與關燈固定採玩家視角。
- 主選單不再顯示同機雙人或AI測試／回放入口。僅在主選單可按 `Ctrl+F8` 開同機雙人、`Ctrl+F9` 開AI測試／回放；對局中不接受這兩組快捷鍵。原本 `F3` 對局紀錄仍可使用。
- PvE完成或離開時自動保存回放於 `saves/replays`；再玩一場保持單人模式與所選角色。開發測試頁可列出內附模型與本機回放，有外部 snorebot 時再額外列出訓練結果。
- 要調整數值或牌堆，先進「設定」。
- 主選單「新手教學」改為清單：關於打呼者、關於打巴掌者、關於卡牌。卡牌有四關：改變波型、建立優勢、改變時間、改變戰局。每關固定手牌、抽牌順序和對手操作，親自點選指定流程；角色關含唯一解的選牌測驗，選錯只提示重選，不執行錯牌。
- 完成一關後回到進入該關的清單，顯示完成勾記，可重玩。途中返回不算完成。教學清單不提供單人模式捷徑；離開教學回主選單，單人模式由主選單獨立進入。
- 劇本在 `data/tutorial/lessons.json`；可任意插入圖卡步驟。圖卡PNG放於 `assets/tutorial/`，命名與劇本image欄位對應；未提供PNG時顯示文字說明卡。編輯方式見 `data/tutorial/README.md`。
- 教學為固定牌與固定盤面，使用正式規則計算；不保存教學對局、不跳成就，也不改動平衡設定或牌堆。各關完成狀態僅存本機 `saves/preferences.json` 的 `tutorial_completed`，不提交Git。示範盤面不代表一般對局的固定開局。
- 設定分為「音效／對局設定／卡牌組成」：音效預設70%，支援音量條、＋／－及出牌音效試聽；音量即時生效，按「儲存設定」保留。
- 出牌成功時播放短促刷聲；選牌預覽、略過或操作失敗不播放。0%音量為靜音；缺少音效裝置時仍可遊玩。
- 開局自動落點並進入行動。出牌、換牌或略過後自動換人落點，鏡頭平滑移動後即可繼續行動。
- 打呼者在高度達到正負閾值時，可得固定分或額外抽一張，也可略過。
- 打巴掌者在正高度可打巴掌。得分暫為 `int(高度 / 巴掌分母 + 得分加成)`，需平衡測試。
- 巴掌清除效果、雙方道具，跳過出牌，直接交給打呼者下一次落點；目前橫軸持續。
- 選手牌後出 1 張並補滿上限，或棄 1 抽 2，也可略過；滑鼠滾輪或左右箭頭捲動手牌。
- 道具出牌後裝備，下一個自己的回合起使用。每回合最多一次，可以和角色行動任意排序。只有空欄能裝備。
- 上方落點固定於波形區內部寬度的 1/2；過去保留，未來可見範圍受預覽設定控制。
- PvE不公開電腦手牌；開發用同機雙人模式不遮手牌。尚未實作連線，預計後續擴充。
- `F3` 開關紀錄視窗；`Esc` 返回主選單。回到選單後新開對局會建立新遊戲，尚未提供中途存讀檔／恢復按鈕。

## 新增卡牌／道具

複製 `data/cards.json` 中一筆資料，給不同 `id`，修改 `copies` 與 `effects` 即可組合既有效果。不需要在回合流程判斷卡名。

波形處理器在 `effects.py` 用 `@wave_handler('新種類')` 註冊。全新道具在 `TOOL_HANDLERS` 註冊函數，再於卡牌的 `tool` 指定種類及參數。新狀態／即時效果則需補上規則核心的領域處理，不能僅填未註冊名稱。

持續效果依加入順序處理。波形變更約 0.5 個橫軸時間單位漸入，暫時效果到期前約 0.5 單位漸出；巴掌重置也平滑過渡。舊版本保留歷史，永久效果也能被巴掌清除。`data/config.json` 的 `wave_fade` 可調整此長度。

## 本版測試決策（可再調整）

- 振幅／閾值 50、週期 12、間隔 1.5、總長 45、預覽 3；打呼得 10 分，巴掌高度除以 5 取整數。
- 恰好等於終點可完成該回合，只有超過才結算。縮短終點至目前位置之前時，該牌結算後立即結束。
- 漫漫長夜／天快亮了的終點增減不被巴掌清除；落點間隔效果仍會清除，目前 x 不歸零。巴掌不能倒轉已完成的抽牌、分數與歷史。
- 角色行動每回合最多一次；使用道具不重新給予角色行動。主動棄道具不算使用次數。
- 抱枕只改目前縱軸落點，朝 0 移動 50 且可穿越 0，不修改函數與過去曲線。
- 波形加成從出牌位置之後漸入，期間採 `[開始, 結束)` 並於到期前漸出；原落點保持不變。sin 加成從效果起點計算相位。
- 基礎振幅／週期牌依當前基礎分量計算改動差值，再加入當前運算結果；先前的放大不會回頭套在後來的新改動上。後加入的放大則作用於整體。
- 「關燈」先只遮波形區；「夢境重整」棄掉自己的剩餘手牌、抽回同張數，再照一般出牌規則補滿上限，可能抽回同牌。
- 棄掉的牌及所有離場道具都進共用棄牌區；若抽牌與棄牌區皆空，就不補牌。
- 成就為測試範例：同一玩家連續三次出同種牌（棄牌／略過中斷）、正負兩側得分、用完所有巴掌、完成對局。進度本局計算，解鎖跨局共用保存。

### 共用卡牌／道具說明框（2026-11-17）

- 手牌卡面只顯示牌名，不再塞分類與敘述；一次顯示四張，其餘以滾輪或箭頭捲動。
- 手牌右側固定說明框，點選手牌時顯示牌名、分類與完整敘述；波形牌同時保留選牌預覽。
- 行動階段提供「查看道具」，下方裝備欄也可點選；共用說明框顯示道具敘述、剩餘次數與可用狀態。
- 查看道具不等於使用；使用與棄掉仍有獨立按鈕。選道具會取消手牌選擇及波形預覽，反之亦然。
- 長敘述可將滑鼠移到說明框內滾動閱讀，不影響手牌捲動。

### 打呼者回合得分（2026-11-17）

- 新增基本設定「打呼回合得分」，預設 1，可調整為非負整數，0 表示關閉。
- 打呼者每次成功落點並進入行動階段，自動取得此分數；開局與巴掌後的新回合均計入，超終點未落點則不加分。
- 不占用角色行動，適用一般得分加成；基礎回合得分設定本身不會被巴掌清除。以 snore_turn_scored 事件獨立記錄，避免觸發打呼正負側得分成就。

### 急促呼吸相位修正（2026-11-17）

- 改週期時，以出牌橫軸位置為錨點接續原本的基礎相位，只改未來的相位前進速度，不再以 x=0 重算整段 sin。
- 多次改週期會接續前次相位；之後改振幅也沿用相位。FIFO、過去歷史、固定閾值、漸入漸出與選牌預覽不變。


### 巴掌指數計分（2026-11-17）

- 巴掌分數改為 ceil(底數 ** 目前落點高度 + 得分加成)，最少 0 分。預設底數 1.05，取代原本高度除以分母的計分方式。
- 基本設定以「巴掌底數」呈現，每次調整 0.01，最低 1.00；其餘設定步長不變。
- 基本設定同步顯示正閾值的巴掌基礎得分，不包含個別對局中的卡牌加成；更改底數或振幅／閾值即更新。
- 例：底數 1.05、正閾值 50 時得 12 分；高度 100 得 132 分。這個靜態參考不顯示目前落點高度。
- 舊存檔的 slap_divisor 不再使用；缺少新欄位時以預設 slap_base=1.05 載入，其餘已存設定與牌組保留。

2026-11-19 成就調整：「叫醒服務」改為本局所有巴掌機會用完時解鎖，以成功巴掌事件的剩餘次數為 0 判斷，適用自訂次數；既有成就解鎖紀錄保留。

### 好夢加分適用範圍（2026-11-19）

- 好夢加分對所有現有得分來源生效：打呼每回合自動得分、超閾值行動得分與巴掌得分。
- 每回合原本 1 分，+3 後為 4 分；重複加成可累加，巴掌清除加成後回到基礎分。
- 回合得分若在基本設定設為 0，仍視為停用此得分來源，不因加成重新啟用。


### 共用計分入口（2026-11-19）

- `snorebattle/scoring.py`：`calculate_points(base_points, bonus, rounding=...)` 統一套加成、取整與最低 0 分；`slap_base_points` 只算巴掌指數基礎分，`slap_points` 供設定頁預估。
- `Game.award_score(player, base_points, source=..., rounding=...)`：讀取玩家加成、呼叫純計分函式、更新分數並寫入 score_awarded 事件，回傳本次得分。
- 每回合打呼、超閾值行動及巴掌全部改走共用入口。新增得分方法先計算基礎分，再呼叫此入口，不直接修改玩家分數。
- 原有 snore_turn_scored／snore_scored／slapped 等事件仍負責各自成就與行為紀錄；score_awarded 只記錄通用計分明細，不重複觸發得分成就。
- 呼叫範例：`game.award_score(player=0, base_points=5, source='new_method')`。既有計分結果與停用回合得分的規則不變。

## AI 與回放測試

開發者入口改為主選單按 Ctrl+F9，可使用內附模型及本機回放；若同層有 snorebot，另外載入其策略檔與測試紀錄。也可用 `main.py --bot 策略.json --human-role 0` 或 `main.py --replay 回放.json`。回放沿用原畫面，空白鍵暫停／播放、左右鍵逐步；人機與回放不寫入正式成就。策略訓練與結果表操作見 snorebot/README.md。


### 測試提示與回放出牌預告（2026-11-19）

- 回放／人機測試不顯示成就解鎖通知，正式雙人模式保留通知；原有正式成就存檔不變。
