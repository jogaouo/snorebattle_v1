# 中等難度固定模型

- 玩家當打呼者：電腦使用 `loose_1.json`（蓄波、長波、保留短期加倍）。
- 玩家當打巴掌者：電腦使用 `tight_0.json`（先控危險波型，再壓縮回合數）。

這兩個檔案與 `snorebattle/ai/policy.py`、`environment.py` 於2026-11-25由目前snorebot複製封存。`manifest.json`保存雜湊以供核對。遊戲僅讀取專案內附檔案，不讀外部best模型，訓練更新不會自動改變正式難度。

正式PvE和開發測試共用回合控制，但成就／存檔規則分開：正式PvE記錄玩家自己的成就及本機回放；開發試打與回放不解鎖成就。進階模型日後可另外新增，不覆寫這組中等難度。
